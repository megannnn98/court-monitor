## Переменные окружения

Читаются из `.env` (не коммитится) или из окружения. Префикс — `CM_`,
регистр не важен. Значения по умолчанию заданы в
`src/court_monitor/config/settings.py`; здесь — то, что осмысленно менять.

### База и логи

| Переменная | По умолчанию | Описание |
|---|---|---|
| `CM_DATABASE_URL` | `sqlite:///./court_monitor.db` | Строка подключения к БД |
| `CM_LOG_LEVEL` | `INFO` | Уровень логирования |
| `CM_CONFIG_DIR` | `config` | Каталог с YAML-конфигами |

### HTTP-клиент

Значения подобраны так, чтобы не долбить чужие сайты. Ослаблять их без
причины не стоит.

| Переменная | По умолчанию | Описание |
|---|---|---|
| `CM_HTTP_TIMEOUT` | `20.0` | Таймаут запроса, секунды |
| `CM_HTTP_PER_HOST_CONCURRENCY` | `2` | Одновременных запросов на хост |
| `CM_HTTP_DELAY_SECONDS` | `1.5` | Пауза между запросами к одному хосту |
| `CM_HTTP_MAX_RETRIES` | `3` | Число повторов |
| `CM_HTTP_USER_AGENT` | заданный в коде | User-Agent |

### Интеграции

| Переменная | По умолчанию | Описание |
|---|---|---|
| `CM_AIRTABLE_MODE` | `read_only` | Режим Airtable |
| `CM_AIRTABLE_TOKEN` | — | Токен Airtable (нужен не для публичной view) |
| `CM_LLM_MODE` | `disabled` | LLM-извлечение — выключено |
| `CM_LLM_BASE_URL`, `CM_LLM_API_KEY`, `CM_LLM_MODEL` | — | Параметры LLM |
| `CM_NER_MODE` | `disabled` | `spacy` включает NER-извлечение имён |

`CM_NER_MODE=spacy` требует установленного extra `nlp` и модели
`ru_core_news_lg`. NER работает **в дополнение** к regex-извлечению, результаты
дедуплицируются по нормализованному ФИО. Замер на живом корпусе: NER даёт
заметно больше попаданий в реестр, чем один regex.

## Веб-интерфейс оператора

```bash
make run-web                                          # http://127.0.0.1:8010
uv run court-monitor run-web --host 0.0.0.0 --port 9090
uv run court-monitor run-web --reload                 # автоперезагрузка при правках
```

### Страницы

| Страница | URL | Описание |
|---|---|---|
| Дашборд | `/` | Общая статистика, последние документы |
| Документы | `/documents` | Список загруженных материалов |
| Детали документа | `/documents/<id>` | Извлечённые факты с цитатами |
| Совпадения | `/matches` | Кандидаты на сопоставление с реестром |
| Детали совпадения | `/matches/<id>` | Разбор score, подтвердить/отклонить |
| Очередь проверки | `/review` | Сбои парсера, блокировки источников |
| Реестр | `/registry` | Поиск по записям Росфинмониторинга |
| Аудит | `/audit` | Журнал решений оператора |
| Задачи | `/jobs` | Запуск и мониторинг фоновых задач |

### Фоновые задачи

Запускаются со страницы `/jobs`. Выполняются по одной за раз
(`ThreadPoolExecutor(max_workers=1)`); задача того же вида, уже находящаяся в
работе, отклоняется, а не ставится в очередь.

| Задача | Что делает |
|---|---|
| Собрать всё и сопоставить | Все источники и каналы, затем поиск совпадений |
| Собрать источники | Загрузка и разбор без поиска совпадений |
| Разобрать необработанные | Повторный разбор документов в статусе `pending` |
| Загрузить перечень РФМ | Живая загрузка с `fedsfm.ru` |
| Найти совпадения | Сопоставление извлечённых имён с реестром |

Планировщика нет — задачи запускает человек. Отмены запущенной задачи тоже
нет; см. [`ai-context/known-risks-and-notes.md`](ai-context/known-risks-and-notes.md).

### Безопасность

**Аутентификации нет** (D-007). Интерфейс привязывается к loopback, и при
смене хоста на внешний вы получите предупреждение — оно не декоративное.
Изменяющие действия защищены CSRF-токеном, но токен не заменяет вход:
любой, кто дотянется до порта, может подтверждать совпадения от вашего имени.

## JSON API (read-only)

Отдельное приложение от веб-интерфейса оператора.

```bash
make run-api                                # порт 8000

curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/stats
curl http://127.0.0.1:8000/documents
```

## TLS-пиннинг fedsfm.ru

Живая загрузка перечня РФМ идёт с пиннингом на цепочку из
`config/ca/fedsfm_ru_chain.pem` (корень Минцифры + `subca_ssl_rsa2024`).

Важное ограничение, описанное в `config/ca/README.md`: оба сертификата были
получены по соединению, которое нечем было проверить. Пиннинг здесь даёт
**непрерывность** — заметить смену издателя, — но не подлинность.
