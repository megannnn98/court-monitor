# Data ownership inventory

Status: working inventory, 2026-10-17 (branch `refactor/data-ownership`, from `main`
edfe1d3). Generated by a static scan, then read by hand where marked. It is the input of
the data-ownership refactor (ADR 0031) and is deleted or frozen when that is done.

## How it was made

Every Python file of the workspace (`packages/*/src`, `apps/*/src`, `tools/*/src`, the
tests, `migrations/env.py`) was read with `ast`:

- **ORM**: every name imported from `db.orm_models` or `db.models.*` that is an ORM class,
  mapped to its table. WRITE when the file passes the class to `insert(...)`, `update(...)`,
  `delete(...)` or constructs it inside `session.add(...)`/`add_all`/`merge`; READ otherwise.
- **SQL**: every string literal with SQL keywords, matched against the 60 table names.
  WRITE for `INSERT INTO`/`UPDATE`/`DELETE FROM`/`TRUNCATE` of that table.

Limits, to be closed while each file is migrated: a change of an attribute of a loaded ORM
object (`record.status = …`) is a write the scan reads as READ; a query built from a
string the scan cannot see is missed.
