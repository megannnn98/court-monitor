## Технические детали

### HTTP-требования

**User-Agent обязателен:**
```bash
curl -A "Mozilla/5.0 (X11; Linux x86_64; rv:128.0) Gecko/20100101 Firefox/128.0"
```

Без User-Agent сервер возвращает `403 Forbidden`.

**Redirects:**
- Сайты используют `301 Moved Permanently`
- Необходимо следовать редиректам (`curl -L`)

**Кодировка:**
- HTML отдаётся в `windows-1251`
- Требуется конвертация: `iconv -f windows-1251 -t utf-8`

### Ограничения

1. **CAPTCHA:** Не обнаружена при базовом сканировании
2. **Rate limiting:** Не обнаружен, но следует соблюдать этичные интервалы
3. **Robots.txt:** Не проверен, требуется дополнительное исследование
4. **JavaScript:** Базовый контент доступен без JS, но некоторые интерактивные элементы могут требовать рендеринг

### Playwright

**Не требуется** для базового сканирования пресс-релизов. Весь контент доступен через HTTP GET с правильным User-Agent.

Playwright может понадобиться только для:
- Интерактивного поиска дел в `sud_delo` (если формы используют AJAX)
- Динамически загружаемого контента (не обнаружено)
